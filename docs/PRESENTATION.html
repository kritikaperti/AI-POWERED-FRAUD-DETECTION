PROJECT OVERVIEW

AI-Powered Fraud Detection System

An enterprise-grade real-time financial security and anomaly detection platform combining Spring Boot 4, MySQL 8, and an interactive modern web UI.

Executive Summary

  • ⚡
    Real-Time Threat Prevention: Evaluates transactional vectors (amount spikes, velocity, location deviations) in milliseconds.
  • 🧠
    Explainable Security Scoring: Delivers multi-factor risk scores (0–100) with detailed human-readable rationales.
  • 👥
    Dual-Portal Ecosystem: Seamless user experience for account holders alongside high-power investigation tools for compliance admins.
  • 🗄️
    Full ACID Persistence: MySQL 8 backed audit tables for users, transactions, and formal fraud investigation cases.
TECHNICAL ARCHITECTURE

Full-Stack Architecture & Components

Clean separation of concerns designed for high scalability, stateless security, and transactional reliability.

Frontend Client Tier

HTML5 / ES6

Responsive multi-dashboard UI with dynamic SVG risk gauges, alert streams, and client-side fallback simulation via localStorage.

Backend Service Tier

Spring Boot 4.1

Java 26 REST API service running Spring Security 6 with stateless JWT authentication, BCrypt encryption, and fraud scoring services.

Persistence Tier

MySQL 8.0

JPA/Hibernate managed relational database (frauddb) holding users, transaction ledgers, and linked investigation cases.

Scoring Decision Matrix

0 – 39
SAFE / APPROVED
40 – 69
SUSPICIOUS / FLAGGED
70 – 100
BLOCKED / FRAUD CASE

UI / UX OVERVIEW

User Dashboard & AI Fraud Scanner

Clean, modern interface designed to give users immediate feedback and clear explanations on payment safety.

ADMINISTRATION PORTAL

Admin Executive Overview & Case Review

High-visibility dashboard empowering fraud analysts to monitor trends and review flagged cases.

Admin Capabilities

  • 📈
    Executive KPIs: Monitored transactions, safe percentage, suspicious alerts, and blocked high-risk attempts.
  • 🚨
    Flagged Alerts Queue: Centralized queue of suspicious transactions requiring analyst sign-off.

TRANSACTION SURVEILLANCE

Live Transaction Ledger & Reports

Continuous surveillance with instant categorization into Safe, Suspicious, and High Risk.

Surveillance Engine

    Real-Time Ledger: Automatically registers incoming transactions with risk scores and channel data.
  • 🏷️

  • 📑

DATABASE OVERVIEW

MySQL Database Schema & Live Inspector

Relational schema powered by MySQL 8.0 InnoDB engine with full referential integrity and audit records.

Schema Architecture

  • 👥
    users: Stores user accounts, BCrypt password hashes, and security roles (ADMIN/USER).
  • 💳
    transactions: Complete transaction records with amount, merchant, location, timestamp, and risk score.
  • 🚨
    fraud_cases: Linked 1:1 with transactions for high-risk alerts with investigation notes and review statuses.
